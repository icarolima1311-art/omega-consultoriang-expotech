# 🚀 FECAF Telecom - Business Intelligence & Governança de Dados

Projeto desenvolvido pela Ômega Consultoria para a FECAF Telecom utilizando BigQuery, SQL e Looker Studio.

## Objetivo

Transformar dados financeiros e operacionais em informações estratégicas para apoio à tomada de decisão.

## Tecnologias Utilizadas

- Google BigQuery
- SQL
- Looker Studio
- GitHub

## Dashboards Desenvolvidos

### 📊 FinOps & MRR

- Receita Bruta
- Receita Líquida
- Total de Descontos
- Participação por Segmento
- Receita por Bairro

### 🛠️ NOC & Field Services

- Total de Chamados
- SLA Crítico
- Fibra Consumida
- Chamados por Cargo
- Incidentes por Bairro
- Top 10 Tipos de Chamado
